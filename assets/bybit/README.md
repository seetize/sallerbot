# Bybit guide assets

Положите сюда шесть PNG-файлов, нарезанных из присланной памятки:

1. `bybit-step-1.png` — выбор монеты USDT на P2P.
2. `bybit-step-2.png` — оплата и получение криптовалюты.
3. `bybit-step-3.png` — ввод адреса получателя.
4. `bybit-step-4.png` — выбор сети TRC20.
5. `bybit-step-5.png` — подтверждение безопасности.
6. `bybit-step-6.png` — экран успеха.

Бот отправляет шаг 1 после выбора Bybit, а остальные после нажатия кнопки подтверждения.
